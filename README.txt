Gemechu Iticha Mosisa - Portfolio (installable web app)

OPEN OFFLINE: double-click index.html (works as a normal page).

INSTALL AS AN APP: upload this whole folder to any free HTTPS host
(Netlify Drop, GitHub Pages, Cloudflare Pages, Vercel), then open the link:
- Android (Chrome): menu > Install app / Add to Home screen
- iPhone/iPad (Safari): Share > Add to Home Screen
- Windows/Mac/Linux (Chrome or Edge): install icon in the address bar
After the first visit it also opens offline.
